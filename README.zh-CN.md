# mossread · 小纸 Pico（RDP-G01-W）

> **mossread** 是给小纸 Pico（RDP-G01-W）做的社区阅读固件。它建立在 [kiikoread](https://github.com/wegooo-cell/read-pico-reader)（上游 **0.3.3-rc100**，作者 wegooo-cell）与 [MindReset 官方示例固件](https://github.com/MindReset/read_pico_firmware)之上；本仓库是 ismoss 维护的独立分支，产品命名、发布节奏和自建更新源由我们负责，底层能力与功劳归上游作者。这不是 MindReset 或 kiikoread 的官方发布，上游的官网、更新日志、商店、支持渠道与 issue 区不覆盖本固件。

> **许可提醒。** 上游 rc93 及以前为 Apache-2.0；上游 rc94 起明确标注的新增原创内容适用[个人学习许可](licenses/kiikoread-Personal-Study-1.0.txt)（禁止商用）。本项目新增文件按 Apache-2.0 发布，但**组合固件仍包含上游的非商用材料**，请仅用于个人学习与自用，不要商用或售卖。完整范围见 [LICENSE](LICENSE)。

**当前版本**：以线上 [update.json](https://ismoss.github.io/mossread/update.json) 为准（2026-11-05 线上为 `0.3.3-rc100-mod120`） · **更新源**：`ismoss.github.io/mossread` · **设备**：小纸 Pico RDP-G01-W（ESP32-S3 / 16 MB Flash / 684×1216）

## 一、这是什么

一句话：**以 kiikoread 为兼容底座，做成 mossread，把“用起来会皱眉”的地方改顺**。

| 定位 | 说明 |
| :--- | :--- |
| 不是重写 | 首页、书架、文件、设置、阅读、传书、锁屏仍以 kiikoread 为兼容骨架；书籍格式、配置备份、分区表、NVS 键值保持兼容 |
| 不是官方 | 没有 MindReset 或 kiikoread 上游的背书；当前系统品牌为 mossread，更新源是自建的，出问题请找本仓库，不要找上游 |
| 不是一次性魔改 | 有 CI（宿主回归 + 真机时序编译）、自建 OTA feed、按版本记录的 [更新日志](docs/CHANGELOG.md) 和 [路线图](docs/ROADMAP.md) |

二改的重点不是“再加一个功能”，而是四件事：

1. **阅读时真的能横过来**：正文、目录、15 个二级面板、锁屏整套跟随持机方向。
2. **网络像手机一样讲道理**：记住多个 WiFi、换地方自动换网、断网/重连/自动连接都有明确开关和状态。
3. **每个“等半天”的地方都有反馈**：更新、传书、壁纸预览、扫描书架，能看见它在干什么，也能中途退出。
4. **锁屏和刷屏收干净**：密码圈圈、上一页灰线、深睡残影这些 e-ink 老毛病，按真因修。

### 上游 rc100 → rc105：他们改了什么，我们拿什么（2026-11-05 核对）

上游在 rc102–rc105 之间把仓库重构成 Pico + Metalio S31 双板结构（`boards/`），并合入 PR55–75。对 Pico 有实际意义的变更与我们的取舍：

| 版本 | 上游做了什么 | 我们的取舍 |
| :--- | :--- | :--- |
| rc102 | 液态玻璃书架、无配置默认外观、英文 TeX 断词与词间对齐、TXT 分卷目录/快速选卷、文件页看图设壁纸 | 液态玻璃书架已由 mod118 自研；词间对齐 rc100 已有；断词与分卷按需再做 |
| rc103 | 全像素 GL16 翻页、静态 WebP、渐进 JPEG 全解码、EPUB EOCD 尾标记与 EPUB3 无 toc 兼容、文件管理套件、首次引导/系统中英文切换 | WebP（mod84）、渐进 JPEG（mod85）、文件管理（mod88–93）都是我们自己做的；EPUB 两条兼容修复值得拿（小、冲突≈0） |
| rc104 | 书架管理对齐文件页、阅读状态栏/工具栏回归修复、EPUB 脚注弹窗、GIF 首帧、JPEG 解码兜底、双击插图缩放、水波纹擦白/补黑、深睡单击续读 | 书架管理与深睡续读我们已有；脚注/GIF/JPEG 兜底值得拿；水波纹擦白要真机 A/B |
| rc105 | 内建字库扩到 7668 字（16 级灰阶补字、逐字墨量校正）、默认全屏设置、阅读线跟随文字/整行、题头工具栏悬浮不重排、局部刷新精确到像素 | 字库是最大收益（先逻辑 +6KB，后资源 +469KB）；默认全屏/阅读线便宜可拿；悬浮重排风险高 |

**已合入 `mod119` → `mod120`**：① 局部刷新精确像素边界 ② EPUB 两类打不开 ③ 内嵌 GIF 首帧 ④ JPEG 小平面兜底 ⑤ 字体缺字回退（mod119 逻辑 + mod120 的 PIF4 16 级灰阶补字资源）⑥ 书架批量读进度 ⑦ 相数上限 40→64 ⑧ 阅读线「跟随文字 / 整行」开关。

**暂未做**：默认全屏——mossread 阅读页本来就是进书即全屏，单独加开关只有同时做「标准模式进书」才有意义，留给后续单独改动。

**暂不跟进**：书架管理重构（我们已有等价实现，改动面也很大）、题头/状态栏的两处调整（现有实现已经满足，不需要搬）、翻页排除信息栏（与本项目“页脚并进同一次 GL16”的刷新策略不同）、备份文件改名（会破坏已有备份的兼容性）。

| 分支 | 用途 |
| :--- | :--- |
| `main` | 上游源码镜像 + 本固件的门面 README；**不含**固件代码 |

> 为什么更新源要自建：官方源里更高的版本号会把本固件顶掉，设备一联网就被“升级”回上游，横屏锁屏、DNS、远程监看全部消失。自建 feed 从根上避免这件事；代价是本固件设备**不会**再收到官方更新，回退需要手动刷机（见下一节）。

### 刻意没动的东西

- 分区表、双槽布局、OTA 数据分区：不动，TF 卡升级和配置备份继续兼容。
- 书籍格式与解析规则：EPUB/TXT 的既有上限、字体缓存、阅读进度格式保持原样。
- 界面品牌：固件显示为 **mossread**；数据、分区、协议和上游兼容标识保持不变。
- 数据上报：没有账号、没有遥测、没有云端书架。

## 三、安装与回退

### 3.1 前置条件

| 条件 | 要求 |
| :--- | :--- |
| 设备 | 小纸 Pico **RDP-G01-W**（16 MB Flash，双槽 4 MB 布局） |
| 当前系统 | kiikoread **rc72 或更新**的兼容双槽基础包 |
| 存储卡 | FAT32 microSD，根目录可写 |
| 电源 | 升级期间保持供电，不要拔卡 |

不满足“当前系统”时，先用官方网页刷机装一次 kiikoread 正式版（rc72+），再按下面升级。二改仓库只发布**应用镜像**，不发布引导程序/分区表全量包。

### 3.2 从 kiikoread 升级（推荐）

1. 打开 [update.json](https://ismoss.github.io/mossread/update.json)，取 `version` 与 `url`；2026-11-05 线上为 `0.3.3-rc100-mod120`。
2. 下载对应的 `Pico-update-*.bin`，**改名为 `Pico-update.bin`**，放到 TF 卡根目录。
3. 设备上进入 **设置 → 升级和恢复 → 系统升级 → TF 卡升级**，确认后等待写入与重启。
4. 重启后进入 **设置 → 升级和恢复 → 系统升级**，应能看到自建 feed 的版本信息；以后可直接联网检查更新。

直接下载当前版本：
<https://ismoss.github.io/mossread/Pico-update-0.3.3-rc100-mod120.bin>

> 文件名 `Pico-update.bin` 是上游固件约定的兼容名，不要改；每次升级覆盖同一路径即可。

### 3.3 从官方演示系统或其他系统

二改不提供网页全量刷机包。请先在电脑 Chrome/Edge 打开 [kiikoread 官网刷机页](https://kiikoread.com/#flash-action)，用 USB 完整刷入 kiikoread rc72+，再按 3.2 做 TF 卡升级。

### 3.4 回退到上游

二改设备的联网 OTA 只认自建 feed，**不会**提示官方版本。要回退：

1. 电脑 Chrome/Edge 打开 [kiikoread 官网刷机页](https://kiikoread.com/#flash-action)；
2. USB 连接设备，按提示完整刷入官方版本；
3. 若设备无法自动进入下载模式，先在设备上打开 **设置 → 升级和恢复 → BOOT 刷机**。

刷机会替换系统；勾选“擦除设备”会清内部设置与阅读记录。TF 卡上的书、字体、图片不受影响。

### 3.5 数据边界

| 操作 | 内部设置/阅读记录 | TF 卡 | 书籍/字体/图片 |
| :--- | :--- | :--- | :--- |
| TF 卡应用升级 | 保留 | 不动 | 保留 |
| 官方网页完整刷机 | 可能清除（看是否勾选擦除） | 不动 | 保留 |
| 恢复出厂 | 清除 | 不动 | 保留 |

升级前建议在 **设置 → 保存与恢复 → 保存当前配置到 TF 卡** 做一份 `Pico-settings.backup`。**备份含明文 WiFi 密码**，请妥善保管 TF 卡。

### 4.2 阅读页

- **书内横屏**：工具栏“横屏”键三档循环（竖屏 → 横屏·右 → 横屏·左）；正文、工具条、目录、全部二级面板按当前阅读位置重排，进出面板不再转回竖屏。书架、菜单等全局界面保持竖屏。
- **横屏细节**：翻页按整页提交差分（横屏旋转下区域差分只驱动一半正文，真机踩过）；状态栏按旋转宽度重排；水波纹方向跟随旋转；周期清理与插图缩放不再用竖屏硬编码区域。
- **目录与面板**：目录横屏双列每页 8 节；阅读统计（含章节跳转键盘与 30 天图）、阅读设置、翻页模式、按键控制、字体设置、书签、阅读背景预览等 15 个面板全部横屏原生，竖屏布局逐像素不变。
- **首翻不卡**：入书/唤醒首帧输出成功后，同步补完下一页预渲染（有界 250 ms）；冷启动缓存为空时首翻直接命中，不再退化成同步整页重绘。
- **字体不再被“预览”打断**：字体选择面板绘制卡片时不再改正文的字体状态，面板开着时绝不重排正文；点选一律落库，载入/保存失败在面板上写出原因。修掉了“改完字体闪一下回到内建思源黑体”的真因。
- **字体测试页不写设置**：设置里的“字体”演示页只临时换当前字体测光栅速度，不写阅读字体，离开时交还。
- **目录跳转条**：按下只做局部差分，快拖的 SWIPE 按松手坐标落定百分比，不再“怎么拖都停在按下位置”。
- **EPUB 细节**：章节文件名含冒号的 EPUB 可打开；没有目录条目的页不再编造“第 N 节”；整页单图上下居中；插图缩放校验页与布局。

### 4.3 锁屏

- **五种锁屏样式**：阅读票根、壁纸、书架拼贴、透明 PNG 书封、“关闭锁屏”（只清白息屏）。样式与密码保护相互独立。
- **横屏锁屏全套**：从横屏书里锁屏，票根按 1216×684 重排（书封在左、书名/进度/统计在中、右边存根放今日数字与日期），密码键盘横排（数字区在右，锁图标与圆点在左）；拼贴锁屏 4 排 × 8 张横版构图；壁纸、透明书封同样按画布出图。竖屏构图逐像素不变。
- **竖/横两张壁纸**：壁纸锁屏有两个独立槽位，可分别设置 684×1216 与 1216×684；横屏槽不设时跟随竖版居中裁切。删除/改名图片时两个路径同步失效。
- **深睡重启不换方向**：横屏票根锁着 → 深睡 → 按键开机，锁面恢复成横屏，而不是“同一张票根突然变竖版”。密码宽限期照常生效。
- **残影收干净**：回到锁屏面、解锁成功、深睡前都请求整屏 GC16 定稿；密码键盘只做局部 DU，不再把圈圈留在壁纸上。**真因**是 `present()` 固定用 GL16、忽略了“整屏定稿”的请求。
- **密码体验**：四位 PIN，可选解锁宽限期（关 / 5 分钟 / 1 小时 / 8 小时 / 24 小时）；默认单击电源键解锁，可改双击；只保存加盐摘要，普通配置备份不含、也不覆盖密码。
- **壁纸列表**：一页 6 张，空出一整行放“设置横屏壁纸 / 跟随竖版”，按钮不再被底栏切掉一半。
- **透明书封横屏**：取景、居中偏移、阴影边界按当前画布计算，缓存键加入画布尺寸；同一张 PNG 在横竖下是两张合成图。

### 4.4 书架、文件与首页

- **书架分片扫描**：进入书架立即显示“正在扫描书架…”，扫描在每轮循环的时间片内推进，全程可切页、可进书；不再整段冻结界面。
- **索引持久化**：扫描成功后把书架（含分类与触发条件）写入内置存储；冷启动/深睡唤醒毫秒级呈现完整列表，随后在影子数组里静默对账，完成后原位换入，显示全程不闪空。USB 读卡会话结束时 bump 存储版本，电脑端增删的书不会被陈旧索引漏掉。
- **分类与页码**：书架题头可选“全部书籍 / 未分类 / books 子文件夹”，各类别分别记住封面书架和列表书架的页码。
- **文件管理**：列表延伸到底栏下并显示下一页预览行（不可点，翻页交互不变）；修复根目录预览行与翻页器重叠。
- **首页**：续读卡、书夹、时钟、月历保持上游形态；设置/网络状态改为实时刷新，不再显示过期快照（见 4.8）。

### 4.5 网络：WiFi、DNS、更新

- **换环境自动换网（真修复）**：此前“多网自动切换”是死代码——连接前把活动凭据清零，选网函数开头就判定无凭据返回，所以 mod4–mod19 从未生效，到公司只会一直重试家里的热点。现在选网发生在重连/换环境路径上；活动网络不在场就切到在场信号最好的已知网络，失败当轮重试一次，之后 45s→90s→180s 退避。
- **WiFi 已知网络库**：最多 8 个，免密直连；扫描列表标“已保存 · 轻点连接”；遗忘网络同时移出库。自动切换**只对密码已入库的网络生效**，没手动连过一次的网络不会被自动加入。
- **自动连接开关**：网络页“附近网络”右下角、设置 → 连接与时间 → WiFi 同款。新设备默认关；旧设备按原状态继承（只在“键还缺失”的那次开机按有无已保存凭据判定一次并落盘）。关掉后解锁与后台都不再自动联网，只有手动“连接”才联网。
- **真实链路**：设置首页 WiFi 行与 WiFi 子页显示实际关联的 SSID（未连接写“未连接”），不再把保存的网络名当现状。
- **手动断开保持断开**：点“断开”后主循环兜底与解锁自动连不会立刻把它连回来；手动连接或保存即恢复。一次断开只管到下次亮屏。
- **亮屏解除压制**：点过“断开”之后，下次亮屏仍会连当前在场的已保存网络。
- **DNS 设置**（连接与时间 → DNS 设置）：默认**跟随路由器**，不再默认覆盖公共解析器；内置列表 + 自建源在线列表；选择按名称和主备地址持久化，在线列表换序/删项/固件更新都不会把已选项悄悄改成另一组地址。在线更新要求 WiFi 已连接，下载在后台任务，失败保留原列表。
- **自建 OTA**：联网更新优先读自建 feed；官方源不再作为回退，避免更高版本把二改顶掉。保留断点续传、失败重试、完整 SHA 校验、空闲分区写入保护。
- **升级页反馈**：进入页面不再自动检查（mod49）；检查/下载的点点点与秒数按行尾对齐；下载显示实时速率（与进度条同一行）；下载跟随重定向；读块静默窗口 30s→90s，慢网抖动不再轻易判失败；检查失败分“未联网 / 连不上服务器 / HTTP 状态异常 / 清单无效 / 连接中断”提示；取消不阻塞、TF 安装不被下载挡住；只有真的在下载时才把 TF 卡升级那一栏让给“本次更新”。

### 4.6 传书

- **离开即停会话、接回网络**：离开传书页总是停掉 HTTP 服务与热点；如果刚才连的是 STA 网，再以 `network_only` 把这条网接回来。不再“传完还挂着网页服务”，也不再把你的网一起关掉。
- **计数与文案**：计数器改成“已传输 N 个文件”（固件、壁纸也算），入口标题改成“WiFi 传输 / 热点传输”；传完后那一行立刻回到“暂无正在传输的文件”，不再挂着上一份文件名和满进度条。
- **网页端壁纸**：上传页裁剪区新增“竖屏 / 横屏”，输出 684×1216 或 1216×684，分别写进两个独立壁纸槽；失败提示说明是哪一槽。
- **预览不卡死**：壁纸预览只解码一次并留在 PSRAM（以前每画一帧都重新解码，3 MB 图就是“白屏很久”）；横图顺时针转 90° 铺满竖屏预览区，方向与偏移修正，不再裁切/偏右/截断；缓存键带源文件 mtime，换图不会显示旧预览；离开设置释放缓存。

### 4.7 远程监看

设置 → 连接与时间 → 远程监看：在局域网内用浏览器看设备当前画面，并直接点按、拖动操作设备。

| 项 | 行为 |
| :--- | :--- |
| 默认状态 | 关闭；**每次开机都关闭**，不从 NVS 自动恢复 |
| 鉴权 | 每次手动开启生成只存 RAM 的 128 位一次性密钥；可选四位进入密码（持久开关） |
| 地址 | `http://设备IP:8123/#k=四位密码`；密钥放在 URL `#fragment`，浏览器不会发给服务器，页面再放入请求头 |
| 失效 | 关闭、重启、十分钟无人访问即失效；密钥不写 NVS、不写日志 |
| 触摸 | 注入会话在最后一次触摸请求 1.5 秒后过期；网页中途关掉，本机立刻恢复可控 |
| 画面 | 半分辨率 BMP（载荷约为四分之一），每秒刷新；多客户端串行生成；网页按窗口缩放，8 秒看门狗 + 切回前台重连 |

> 这是局域网工具，不要把它暴露到公网；也不需要端口转发。

### 4.8 设置与刷屏

- **设置分组**：连接与时间（WiFi / 蓝牙翻页器 / 日期与时间 / 远程监看 / DNS 设置）、显示（系统字体 / 系统对比度 / 主页刷新模式 / 首页强刷 / 自动休眠锁屏 / 双击解锁 / 关机睡眠）、个性化功能（书架样式 / 锁屏样式 / 锁屏密码 / 状态栏签名）、升级和恢复。
- **DNS 搬家**：从“个性化功能”挪到“连接与时间”，和 WiFi、对时、远程监看同组；两组行数 4+5 → 5+4，页面总高与“升级和恢复”位置不变。
- **开关纯黑白**：灰色轨道在滚动差分扫描下会经过深色过渡产生黑闪；黑白无灰阶过渡，任何刷新模式都不再闪。
- **换页整屏定稿**：进出二级页整屏 GC16 一次，上一页列表的灰线残影不再留在最下面。
- **设置主页提示行**：移到标题右侧同一行，按标题实际墨迹垂直居中；任何字面高度的自导入字体都不会再与“设置”标题重叠。
- **网络状态实时**：设置主页不再停留在旧快照，后台连上/断开时那一行和状态栏立刻跟着变。
- **悬浮玻璃底栏**：四个主页面使用玻璃胶囊底栏；普通刷新模式采样底栏之下的页面内容，快刷/水波纹保持固定浅灰胶囊；局部刷新不重算玻璃。
- **锁屏关闭档**：锁屏只清屏息屏，不显示票根/壁纸/拼贴；默认单击电源键直接回原页面，密码开启时仍先验证。

### 4.9 逻辑层的根因修复

这些不是“加功能”，是把“看起来好了、其实没生效”的路径挖出来。按“现象 → 真因 → 修法”列几条代表性的：

| 现象 | 真因 | 修法 | 版本 |
| :--- | :--- | :--- | :--- |
| 到公司只连家里热点 | 选网前活动凭据被清零，选网函数直接返回（死代码） | 选网放到重连路径，活动网络不在场才换网 | mod20 |
| 网页一直 waiting + 破图 | BMP 头 `biPlanes`/`biBitCount` 是 16 位字段，只写了低字节，高字节是堆脏数据 | 54 字节头先整块清零再逐字段写；宿主测试 0xFF 预填充 + 整头金标准 | mod25–26 |
| 检查更新时点点点/秒数从不出现 | 动画由联网任务的等待回调驱动，任务一启动回调就被注销 | 改由界面主循环每秒驱动 | 二改线早期 |
| 字体改完闪回思源黑体 | 预览面板还原正文字体失败后静默退回内建，下一次刷新整本重排 | 绘制不改正文状态；面板开着不重排；点选必落库 | mod31–32 |
| 回到锁屏留密码圈圈 | `present()` 固定 GL16，忽略“整屏定稿”请求；深睡前也没有清白定稿 | 回锁屏面按 GC16 定稿；深睡前清白 + 整屏定稿 | mod51–52 |
| 密码宽限期点按卡死 | 档位循环把位标志当索引（`& 4`） | 有界查表，5 档循环 | 二改线早期 |
| 横屏翻页只驱动一半正文 | 区域差分在横屏旋转下真机只覆盖一半 | 横屏翻页按整页提交差分 | 二改线早期 |
| 壁纸预览白屏很久 | 每画一帧都重新解码大图 | 只解码一次留 PSRAM，缓存键带 mtime | mod37–38 |
| 传完网页服务还挂着 / 网被关掉 | 离开页面只停热点，STA 会话处理不一致 | 离开总是停会话，STA 以 network_only 接回 | mod48 |
| 下载中点取消要等很久 | 取消要等任务收尾，且 TF 安装被下载挡住 | 取消不阻塞；只有下载中才让出 TF 栏 | mod48 |

> 验证方式在每条 changelog 里标注了“真机 / 串口日志 / 代码级推演 / CI”。**宣称 ≠ 证据**，见第六节。

### 4.10 已知限制

- 只面向 **RDP-G01-W**；Metalio EINK 4 Plus 是上游的另一条线，本二改不覆盖。
- 不提供二改网页全量刷机；从官方演示或其他系统首次进入需要先装 kiikoread rc72+。
- 远程监看是局域网工具，默认关闭，无公网鉴权/加密方案；不要端口转发到公网。

## 七、从源码构建

需要 **ESP-IDF v6.1**，目标 ESP32-S3：

```sh
python3 tools/prepare_tls_bundle.py "$IDF_PATH"
idf.py set-target esp32s3
PICO_PROJECT_VER=0.3.3-rc100-mod120 idf.py build
```

- `sdkconfig.defaults` 是本开发板的 Flash/PSRAM 时序；`sdkconfig.ci` 只用于编译检查，不要把 CI 时序当产品默认。
- `prepare_tls_bundle.py` 只修 ESP-IDF 6.1 对“证书包合成根”的有效期处理，不关闭真实证书有效期、主机名或签名校验。
- 应用镜像在 `build/Read_Pico.bin`；TF 升级包需要命名为 `Pico-update.bin`。

CI 与发布：

| 工作流 | 触发 | 做什么 |
| :--- | :--- | :--- |
| `mod-build` | push 到二改分支 | 宿主回归 + 真机时序编译 |
| `mod-build` | 手动 dispatch（必须带 `--ref mod/glass-dock-lockoff`） | 测试/编译通过后发布最小 OTA feed 到 GitHub Pages，并做线上自检 |
| `pages.yml` | `main` 上的网站文件变化 | 发布上游网页刷机站（不是二改 feed） |

> `mod-build.yml` 只在二改分支存在，`main` 是上游镜像故意没有它；不带 `--ref` 会报 “Workflow does not have workflow_dispatch trigger”。

## 八、隐私与安全

- 固件没有遥测、账号或云端书架；不会上传书籍、阅读记录或设置。
- 联网只用于：更新检查、联网对时、可选 DNS、用户主动发起的传书、手动开启的局域网远程监看。
- 远程监看：默认关闭、每次开机强制关闭、一次性 RAM 密钥（可加四位密码）、十分钟无人访问自动关、触摸注入 1.5 秒过期；密钥不写 NVS、不写日志。
- 锁屏密码只保存加盐摘要；普通配置备份不包含、恢复时也不覆盖密码凭据。
- 配置备份含**明文 WiFi 密码**；分享日志/备份前先脱敏。
- 二改不关闭 TLS/SHA 校验，不引入任意镜像源；OTA 只认自建 feed。
